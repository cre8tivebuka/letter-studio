# Letter Studio

This repository is the source of truth for Letter Studio.

- Source and future changes belong on GitHub: cre8tivebuka/letter-studio.
- Build and publish through the GitHub Actions workflow and GitHub Pages.
- Do not publish or synchronize this project through ChatGPT Sites.
- Keep document conversion in the browser; there is no application account system or backend.
- Preserve the supplied logo and the cobalt, midnight, ice white, silver, and steel palette.
- Use npm run typecheck and npm run build for validation.
- For document/layout behavior, run the relevant browser regression checks.
- Never commit credentials, uploaded user documents, node_modules, or generated dist/ files.
